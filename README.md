# css-landingpage
Classname: TOGRAMMER     
A personal brand: TAN1CPY

This project is a landing page exercise that evaluates the CSS skills obtained/learnt in the CSS Flexbox section by
challenging the student to  apply almost every single flexbox skill to construct a web page that is closer to the
 model image of the finished project.


It is during this particular project that I discovered that, the people who manage to really achieve mastery in
tech are not people who are taught spoon-fed quality information, but those who discover high quality information
by way of their own private studies, projects, research, and experiments.
